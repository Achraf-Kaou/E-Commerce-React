# About Mina Store

Mina Store is a React e-commerce learning project focused on building a complete storefront workflow from product listing to checkout.

## What this project demonstrates

- Building a multi-page SPA with React Router
- Managing cart state using Context API + Reducer
- Integrating Firebase Firestore and Storage for real-time product/order data
- Implementing a basic admin side for product creation and deletion
- Handling form validation for contact and checkout experiences

## Intended Use

This project is best suited as:

- A portfolio/demo application
- A base for extending into a production-ready e-commerce app
- A practical example for React + Firebase integration

## Scope

The current version emphasizes core functionality and UI flow. Security hardening, production-grade auth, and CI quality gates still need improvement before production deployment.
